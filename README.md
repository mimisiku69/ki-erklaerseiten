# KI-Erklärseiten

Interaktive Seiten, mit denen ich in Trainings KI-Grundlagen greifbar mache. Die Teilnehmenden probieren selbst aus, statt Folien zu lesen.

**Live ansehen:** https://mimisiku69.github.io/ki-erklaerseiten/

| Seite | Worum es geht |
|---|---|
| [Das Matroschka-Prinzip der KI](matroschka-prinzip-ki.html) | Wie KI, Machine Learning, Deep Learning und Generative KI ineinanderstecken. Ein Zoom-Rundgang durch die Begriffe, mit ihrer Herkunft. |
| [Overfitting und Underfitting](overfitting-regler.html) | Ein Schieberegler verändert die Komplexität eines Modells. Man sieht, wann es zu einfach ist, gut verallgemeinert oder nur auswendig lernt. |
| [Fehlermatrix](fehlermatrix-regler.html) | Ein Spam-Filter mit einstellbarer Schwelle. Fehlalarme und übersehene Fälle hängen sichtbar voneinander ab. |
| [Wortwolke: Welches Sprichwort wird gesucht?](wortwolke-sprichwort.html) | Ein Rätsel zum Einstieg: Jede Verbindung trägt eine Wahrscheinlichkeit. Wer immer den höchsten Wert wählt, findet das Sprichwort. So schreibt ein Sprachmodell Wort für Wort weiter, ohne zu verstehen. |
| [Das selbstlernende Skill-Betriebssystem](skill-betriebssystem.html) | Meine eigene Skill-Architektur für die Arbeit mit KI-Agenten: Ebenen, gemeinsamer Bauplan und ein eigenes Gedächtnis je Skill, das Fehler nicht zweimal passieren lässt. Ein Zoom-Rundgang mit impress.js. |

## Wie die Seiten gebaut sind

- Jede Seite ist eine einzelne HTML-Datei, ohne Build-Schritt und ohne Server.
- Gebaut habe ich sie mit KI-gestütztem, agentischem Programmieren. Inhalt, Didaktik und Prüfung liegen bei mir.
- Barrierearm angelegt: deutsche Sprachauszeichnung, Tastaturbedienung und Beschriftungen für Screenreader.
- Die Zahlenbeispiele sind erfunden und dienen nur der Veranschaulichung.
